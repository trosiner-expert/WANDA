WANDA Arbeitsplatz Setup

Automatisierte Einrichtung eines neuen WANDA-Arbeitsplatzes inklusive PCMS, NeoPrint Druckdienst und Citrix Workspace App.

Download

Version 3.0

Das Setup richtet einen neuen Arbeitsplatz automatisch für die Nutzung von WANDA ein.

Setup herunterladen

Downloadgröße: ca. 487 MB

eventuellen Warnhinweis ignorieren und "Beibehalten" klicken

Installierte Komponenten

✅ PCMS 4.0
✅ NeoPrint Druckdienst
✅ Citrix Workspace App 26.3.20
✅ .NET Framework 3.5 (falls erforderlich)
✅ Windows-Dienstkonfigurationen

Voraussetzungen

  • Windows 11 Professional
  • Windows 11 Enterprise
  • Windows 11 IoT Enterprise
  • Lokale Administratorrechte
  • Internet- bzw. Netzwerkverbindung empfohlen
  • Bei PC-Tausch müssen PC-Name und IP-Adresse übernommen werden

Installation

  1. Setup herunterladen
  2. eventuellen Warnhinweis ignorieren und "Beibehalten" klicken
  3. Setup als Administrator starten
  4. Standort eingeben (z.B. TV, WW-Klein, Büro, Service oder Kasse)
  5. Druckerinstallation ist aktiv, ggf. deaktivieren
  6. Installation starten
  7. Nach Abschluss Citrix Workspace starten

Fehlersuche

Citrix-Farm nicht erreichbar

  • Netzwerkverbindung prüfen
  • VPN-Verbindung prüfen
  • DNS-Auflösung prüfen

Druckdienst fehlt

Installer erneut starten und den Reparaturmodus für den Druckdienst ausführen.

PCMS fehlt

Installer erneut starten und den Reparaturmodus für PCMS ausführen.
